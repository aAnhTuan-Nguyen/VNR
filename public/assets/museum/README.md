# Museum asset notes

The files in `history/` are local copies of the Wikimedia Commons files named in `src/content/history.ts`. The app shows their creator, date, source page and license in the source modal.

`archive-wall-texture.png` is a decorative archive-wall / paper texture generated for the visual layer. It contains no historical person, event, flag, logo or readable document text and must not be presented as historical evidence.

No remote image URL is used by the runtime scene.
